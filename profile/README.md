**DLSS 5 Installer** is a portable Windows utility for installing and managing DLSS 5 components in compatible PC games and supported emulators. It brings game discovery, executable detection, graphics API selection, component installation, and file restoration into one workflow.

Instead of manually searching through game directories and replacing files yourself, you can scan your existing game libraries, select a title, choose the appropriate integration mode, and install the required components. Original files are backed up before modifications, so you can revert changes using the built-in **Restore Originals** feature.

## How DLSS 5 Installer Works

- **Find your games:** Scan Steam, Epic Games, and GOG libraries automatically, or add a custom game directory.
- **Detect the configuration:** Select the game's executable and identify the graphics API used by the application.
- **Choose an integration mode:** Use Native DLSS for supported configurations or experimental DLSS5-Feeder mode for testing in games without native integration.
- **Install and restore:** Apply the selected components with one click, keep backups of original files, and restore them whenever needed.

## DLSS 5 Installation Modes

### Native DLSS

For games with existing native DLSS support, the installer lets you update or replace the relevant DLSS components without manually navigating game folders.

### Experimental DLSS5-Feeder

DLSS5-Feeder provides an experimental approach for testing DLSS 5 integration in games without native support. Compatibility depends on the target game, its rendering configuration, and the components available. Successful integration is not guaranteed for every title.

## How to Install DLSS 5

1. Download the latest release of **DLSS 5 Installer** from the [release page](https://github.com/DLSS-5-Installer/.github/releases/download/1.0.0/DLSS-5-Installer-Windows-x64-v1.0.0.zip).
2. Extract the downloaded archive and launch the application.
3. Allow the installer to scan your Steam, Epic Games, and GOG libraries.
4. If your game is not listed, use the manual add option to select its installation directory.
5. Select the desired game and verify that the correct main executable (`.exe`) is detected.
6. Choose **Native DLSS** for supported native configurations, or enable experimental **DLSS5-Feeder** mode when testing a game without native support.
7. Select the graphics API manually if required.
8. Click **Install DLSS 5** and wait for the operation to finish. Original files are backed up before changes are applied.
9. Launch the game and verify the result. When using DLSS5-Feeder, the ReShade menu may help confirm whether the required effects have loaded.

> **Tip:** Close the game and related background processes before installation to prevent file access conflicts.

## Restore Original Game Files

DLSS 5 Installer backs up original files before applying modifications. To undo an installation, select the affected game in the application and choose **Restore Originals**.

This restores the backed-up files, allowing you to return to the previous configuration when needed.
